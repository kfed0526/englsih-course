# 公園場景素材

使用內建 imagegen（非 CLI）生成融合圖。完整提示詞與參考來源見 [park-scene.prompts.json](./park-scene.prompts.json)。

成品：[park-nickson-bench-watercolor.png](./park-nickson-bench-watercolor.png)。

人物來源為家長提供的 `S__30826527_0.jpg`：保留 Nickson 的臉、髮型、棕色恐龍上衣、綠色車子短褲、白色鞋子與木椅坐姿；原始照片留在受 Git 排除的本機參考庫，沒有改寫。場景以既有 `neighborhood-festival-watercolor.png` 為畫風參考。

畫面包含樹蔭下的 Nickson 與木椅、後方水池、秋千、木塔溜滑梯、右側沙坑與跳跳床。人物、光線、背景整合在同一張圖內，沒有在圖片烘焙文字、按鈕或遊戲熱區。設施文字由 HTML 提供。本階段只開放場景欣賞，未加入遊戲與課程紀錄。
